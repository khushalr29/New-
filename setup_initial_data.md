# HRMS Initial Data Seeding

This document outlines the data populated into the database to ensure the HRMS runs correctly in a fresh environment.

## 1. Django ORM Seeding Script
The recommended way to populate your database is through the Django shell. Run `export PYTHONPATH=$PYTHONPATH:/path/to/shared && python3 manage.py shell` and paste the following:

```python
from shared.models.core.user import User
from shared.models.core.company import Company
from shared.models.core.role import Role
from shared.models.hr_management.hr_masters import CompanyType, Department, Designation, Branch

# 1. Setup Company Type
ctype, _ = CompanyType.objects.get_or_create(company_type='Service', defaults={'description': 'General Service'})

# 2. Setup Default Company
company, _ = Company.objects.get_or_create(
    company_code='TEK001', 
    defaults={
        'company_name': 'Telepathy Tech', 
        'company_type': ctype,
        'sub_domain': 'telepathy',
        'no_of_users': 100,
        'no_of_employees': 500,
        'payment_status': 'paid',
        'amount_paid': 10000.00
    }
)

# 3. Setup Default Roles
admin_role, _ = Role.objects.get_or_create(name='Admin', company=company)
hr_role, _ = Role.objects.get_or_create(name='HR Manager', company=company)
manager_role, _ = Role.objects.get_or_create(name='Manager', company=company)
employee_role, _ = Role.objects.get_or_create(name='Employee', company=company)

# 4. Assign Superuser to Company and Role
user = User.objects.filter(email='admin@gmail.com').first()
if user:
    user.company = company
    user.roles.add(admin_role)
    user.save()
    print(f"User {user.email} initialized with Company {company.company_name} and Admin role.")

# 5. Setup HR Master Data
dept_it, _ = Department.objects.get_or_create(department='Information Technology', company=company, defaults={'unique_code': 'IT001'})
dept_hr, _ = Department.objects.get_or_create(department='Human Resources', company=company, defaults={'unique_code': 'HR001'})
dept_finance, _ = Department.objects.get_or_create(department='Finance', company=company, defaults={'unique_code': 'FIN001'})

Designation.objects.get_or_create(title='Lead Developer', department=dept_it, company=company)
Designation.objects.get_or_create(title='Software Engineer', department=dept_it, company=company)
Designation.objects.get_or_create(title='HR Specialist', department=dept_hr, company=company)

Branch.objects.get_or_create(branch_name='Main Headquarters', company=company, defaults={'city': 'New York', 'phone': '1234567890', 'zip_code': '10001'})

print("Master data seeding complete.")
```
